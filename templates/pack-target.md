# Pack Target Prompt

Use this structure for each content-pack target. Each target uses the same research brief but has a distinct job.

This template is not a complete `image-prompt.md`; it is a planning/reference structure for target differentiation that feeds a normal `image-prompt.md` with Prompt Preflight and Final Generation Prompt.

## Director Lane

State `social` or `infographic`.

## Target Role

Name the target and the outcome it should create for the viewer.

## Crop And Platform

State the intended crop, platform, and reading context.

## Text Budget

State the exact P0/P1/P2 budget for this target.

## Shared Source Story

Summarize the source-backed story this target shares with the rest of the pack.

## Composition Archetype

Choose one archetype or grammar and explain why it fits this target.

## Difference From Other Pack Assets

State how this target differs from the sibling assets in density, composition, focal point, and text load.

## Required Text With Priority

- P0: Exact labels that must appear.
- P1: Exact labels that may appear if space allows.
- P2: Labels to represent with icons, structure, paraphrases, or omit.

## Negative Constraints

List up to five target-specific omissions.

## Target-Specific Quality Gate

State how to judge whether this target succeeds.

## Output Check

Confirm that the target is source-grounded, distinct from sibling assets, and within its text budget.
